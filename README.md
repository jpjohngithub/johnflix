# 🎬 JohnFlix — Streaming de Filmes e Séries

JohnFlix é uma plataforma moderna de streaming de filmes e séries inspirada no design da Netflix, construída com JavaScript Vanilla, HTML5, CSS3 responsivo e integração direta às APIs abertas do Stremio (Cinemeta, FenixFlix, FrostStream, Brazuca Torrents, Mico Leão, Torrentio, WarezCDN, VidSrc PT e Web Players HD).

## ✨ Funcionalidades principais

- **Navegação Estilo Netflix / Disney+**:
  - Interface escura de alta fidelidade com tipografia Inter e micro-animações.
  - Barra de navegação responsiva mobile no rodapé para navegação com uma só mão.
- **Suporte a Filmes e Séries Completo**:
  - Seleção por gêneros, catálogo de mais populares e destaques em HD.
- **Múltiplos Provedores de Vídeo & Dublados PT-BR**:
  - Integração com mais de 15 fontes por título (WarezCDN PT-BR, FenixFlix, FrostStream, VidSrc PT, AutoEmbed, 2Embed, VidLink Pro e Torrentio).
- **Sem Cadastro, Sem Instalação, Sem Anúncios Travando**:
  - Roda 100% no navegador sem necessidade de backend local.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 & CSS3**: Design system com variáveis CSS, Glassmorphism e layout fluido.
- **JavaScript (ES6+)**: Consumo assíncrono de APIs REST Stremio, busca debounced e manipulação de DOM.
- **HLS.js / WebTorrent**: Suporte a transmissões `.m3u8` e streaming via torrent diretamente no navegador.

## 🚀 Como Rodar Localmente

1. Clone este repositório:
   ```bash
   git clone https://github.com/jpjohngithub/johnflix.git
   ```
2. Abra a pasta do projeto:
   ```bash
   cd johnflix
   ```
3. Abra o arquivo `index.html` em qualquer navegador ou utilize o Live Server do VS Code.
